# 매치인덱스 Android 오버레이

Android 8.0 이상에서 사용할 수 있습니다. 앱에서 **오버레이 실행**을 누릅니다. 처음 실행할 때는 **설정 열기**를 누르고 시스템 설정에서 **매치인덱스 오버레이**의 **다른 앱 위에 표시** 권한을 허용합니다. 앱으로 돌아오면 분석창이 열립니다. 작은 창 상단을 잡아 이동하고, 크기 버튼으로 줄이거나 펼칠 수 있습니다. 창 안의 **경기 목록**으로 돌아가 다른 경기를 고를 수 있습니다. **닫기**를 누르면 오버레이가 종료됩니다.

웹 배포의 `?view=overlay` 화면을 사용하므로 경기표와 분석 갱신이 웹과 같습니다. 테스트 APK는 로컬 테스트 키로 서명합니다.

## Windows에서 테스트 APK 만들기

Android SDK Platform 36, Build Tools 36.0.0과 JDK를 설치하고 `ANDROID_HOME`, `JAVA_HOME`을 지정합니다. 이 폴더에서 다음 명령을 실행합니다.

```powershell
.\Build-TestApk.ps1
```

생성 파일은 `build/local/matchindex-overlay-test.apk`에 있습니다. 실기기에서는 권한 허용, 홈 화면으로 이동, 다른 앱 위에서 경기 전환과 상세 열기, 크기 조정, 닫기를 확인합니다.
